# Telegram-бот оплаты для водителей

Python · aiogram 3 · SQLite

Выбор тарифа, реквизиты, отправка фото или текста администратору, ручное подтверждение и проверка срока. Подтверждение не проверяет банковский перевод автоматически и не предоставляет доступ к группе Telegram.

## Запуск

Нужен Python 3.10+.

```sh
python -m venv .venv
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` рядом с `main.py`. Заполните токен, числовой Telegram ID администратора и реквизиты. Администратор должен первым открыть бота и нажать Start.

```sh
python main.py
```

Срок отображается по московскому времени. Тарифы начисляют 15 или 30 суток с подтверждения; при продлении оставшийся срок сохраняется. Названия «с 1 по 15» и «с 15 по 30» сохранены из исходника: календарные периоды пока не реализованы.

Ожидание чека сохраняется в SQLite. Подтверждение и продление выполняются одной транзакцией. Запускайте один экземпляр бота. Отправка уведомления пользователю после подтверждения не имеет автоматического повторения: если Telegram отклонит сообщение, срок всё равно сохранён и доступен через /check.

Не публикуйте `.env`, базы данных и реальные чеки. При загрузке через браузер выбирайте файлы вручную: `.gitignore` не защищает от ручной загрузки. Если токен когда-либо публиковался, замените его через BotFather.
